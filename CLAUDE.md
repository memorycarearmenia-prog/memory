# CLAUDE.md

Рабочие правила для этой сессии/репозитория (проект MemoryCare).

## Higgsfield MCP и медиаконтент (фото/видео)

Higgsfield MCP (генерация изображений и видео) подключён и авторизован только
**локально**, на компьютере пользователя (Windows, через `claude.cmd mcp login
higgsfield`). В этой облачной/remote-сессии Higgsfield недоступен — сетевой
прокси окружения блокирует домен `mcp.higgsfield.ai` (403, organization policy).

**Правило:** как только по ходу работы требуется фото или видео —

1. В код/макет/страницу ставится **плейсхолдер** (заглушка нужного размера и
   формата — например, серый блок, `placeholder.jpg`/`placeholder.mp4`, SVG-заглушка),
   чтобы вёрстка и структура страницы были рабочими и видимыми уже сейчас.
2. Одновременно пишется **детальный, готовый к использованию промпт** для
   генерации нужного материала (что изображено/происходит, стиль, ракурс,
   пропорции/разрешение, цветовая палитра, для какой секции сайта, формат
   вывода) — этот промпт передаётся пользователю, чтобы он вставил его в свою
   локальную сессию Claude Code, где Higgsfield реально генерирует контент.
3. После того как пользователь сгенерирует материал локально и пришлёт
   готовый файл — плейсхолдер заменяется на финальный результат.

Не пытаться вызывать Higgsfield-инструменты напрямую из этой облачной сессии —
это заведомо не сработает из-за сетевой политики.
